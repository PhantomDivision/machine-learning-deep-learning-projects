# MINI GPT TEXT GENERATION — PROJECT GUIDE

## 1. PROJECT OVERVIEW

This project builds a small GPT-like language model from scratch using PyTorch.

The model learns to predict the next token in a sequence and uses those predictions to generate text.

### What We Learned

- Tokenization
- Token embeddings
- Positional embeddings
- Self-attention
- Causal self-attention
- Multi-head attention
- Feed-forward neural networks
- Transformer decoder blocks
- GPT architecture
- Next-token prediction
- Model training
- Text generation

## 3. FILE-BY-FILE EXPLANATION

### STEP 1 — config.py

**Purpose:** Stores the project's configuration.

Contains:

- Device selection (CPU or GPU)
- Context length / block size
- Embedding dimensions
- Number of attention heads
- Number of Transformer layers
- Dropout
- Batch size
- Learning rate
- Training epochs

This file controls the model and training settings.

### STEP 2 — data/input.txt

**Purpose:** Contains the training text.

We provide sample sentences about:

- Machine learning
- Deep learning
- Transformers
- GPT

The model learns language patterns from this text.

### STEP 3 — tokenizer.py

**Purpose:** Converts text into numerical token IDs.

Contains:

- Vocabulary creation
- Word-to-ID mapping
- ID-to-word mapping
- encode()
- decode()

Example:

    "GPT generates text"

    [12, 7, 25]

Our implementation uses a simple word-level tokenizer.

Real GPT models generally use subword tokenization such as BPE.

### STEP 4 — dataset.py

**Purpose:** Prepares training examples for next-token prediction.

It:

- Converts text into token IDs.
- Creates fixed-length input sequences.
- Creates corresponding target sequences shifted by one token.

Example:

    Input:  [10, 20, 30, 40]
    Target: [20, 30, 40, 50]

The model learns to predict the next token at every position.

### STEP 5 — attention.py

**Purpose:** Implements the attention mechanism.

Contains:

1. Self-attention
2. Causal self-attention
3. Multi-head attention

Important concepts:

- Query (Q)
- Key (K)
- Value (V)
- Attention scores
- Scaling
- Softmax
- Causal masking
- Multiple attention heads

Causal masking prevents GPT from looking at future tokens.

### STEP 6 — transformer_block.py

**Purpose:** Combines attention and feed-forward networks into a Transformer decoder block.

Contains:

- Multi-head attention
- Feed-forward neural network
- Layer normalization
- Residual connections
- Dropout

The block processes contextual information and transforms token representations.

Our GPT model stacks multiple Transformer blocks.

### STEP 7 — model.py

**Purpose:** Defines the complete GPT language model.

Contains:

1. Token embedding
2. Positional embedding
3. Transformer blocks
4. Final layer normalization
5. Language modeling head

Overall architecture:

    Input Token IDs
          |
          v
    Token Embeddings
          |
          +
    Positional Embeddings
          |
          v
    Transformer Block 1
          |
          v
    Transformer Block 2
          |
          v
    Final LayerNorm
          |
          v
    Linear Language Model Head
          |
          v
    Output Logits

The output logits represent scores for every possible next token.

### STEP 8 — train.py

**Purpose:** Trains the GPT model.

Training workflow:

1. Load training text.
2. Create tokenizer and vocabulary.
3. Prepare the dataset.
4. Create DataLoader.
5. Initialize GPT model.
6. Define cross-entropy loss.
7. Define AdamW optimizer.
8. Run the training loop.
9. Calculate prediction loss.
10. Backpropagate gradients.
11. Update model parameters.
12. Save the trained model.
13. Save the tokenizer vocabulary.

The model learns to predict the next token.

Saved outputs:

    models/gpt_model.pth
    models/tokenizer.json

### STEP 9 — generate.py

**Purpose:** Loads the trained model and generates new text.

Generation workflow:

1. Load tokenizer vocabulary.
2. Load trained GPT model weights.
3. Accept a text prompt.
4. Convert prompt into token IDs.
5. Pass tokens through GPT.
6. Get next-token logits.
7. Select the token with the highest score.
8. Append the predicted token.
9. Repeat until the generation limit is reached.
10. Convert token IDs back into text.

Our current implementation uses greedy decoding (argmax).

## 7. IMPORTANT THINGS TO REMEMBER

1. GPT is a decoder-only Transformer.
2. GPT uses causal self-attention.
3. The model predicts the next token, not the entire sentence at once.
4. Training teaches the model to predict tokens from examples.
5. Generation repeatedly predicts and appends one token at a time.
6. Our tokenizer is a basic word-level tokenizer, not GPT-2's BPE tokenizer.
7. Our training dataset is very small, so the model can memorize the examples rather than learn general language.
